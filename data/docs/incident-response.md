# Incident response
This is a fictional AcmeDesk handbook used only for the demo.

## Outage reports
Check the service status page before opening a new outage report.
For an outage ticket include the UTC timestamp, request identifier and affected feature.
Never attach access tokens, passwords or unredacted customer information.

## Severity
A complete service outage is classified as severity one.
A degraded feature with a workaround is classified as severity two.
