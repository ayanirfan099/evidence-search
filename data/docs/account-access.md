# Account access
This is a fictional AcmeDesk handbook used only for the demo.

## Password recovery
Use the Forgot password link on the sign-in page to request a reset email.
Password reset links expire after 30 minutes. Request a new link if it has expired.
If the reset email is missing, check the spam folder and confirm the account email.

## Two-factor authentication
Use a saved recovery code when your authentication phone is unavailable.
If all recovery codes are lost, contact the account administrator to verify your identity.
Never send your password or one-time login code to support.
