# Data exports
This is a fictional AcmeDesk handbook used only for the demo.

## Download reports
Open Reports, choose the date range, then select Export CSV.
Exports containing more than 100000 rows are processed as background jobs.
When a background export is complete, an email contains a download link valid for 24 hours.

## Troubleshooting
If a CSV export is empty, check that the selected date range includes records.
If the report contains non-English text, open the CSV with UTF-8 encoding.
